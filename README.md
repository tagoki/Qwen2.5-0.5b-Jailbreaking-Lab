# Qwen2.5-0.5b-Jailbreaking-Lab

**Практическая лаборатория по Jailbreaking и Prompt Injection для LLM**

Данный репозиторий предназначен для практики читателей Telegram-канала [FadikMachine](https://t.me/fadikMachine) и представляет собой изолированный полигон для изучения техник **Jailbreaking** и **Prompt Injection** на примере языковой модели Qwen2.5-0.5B.

Цель лабораторной работы - исследовать поведение LLM, проверить устойчивость системных инструкций и разобраться в ограничениях современных механизмов защиты языковых моделей.

> [!WARNING]  
> Лаборатория предназначена исключительно для обучения и контролируемых экспериментов. Все исследования проводятся на локально запущенной модели. Не переносите экспериментальные техники на сторонние системы без разрешения их владельцев.

## Загрузка и установка

Лаборатория разворачивается с помощью **Docker**. Все необходимые конфигурационные файлы находятся в репозитории, а языковая модель загружается отдельно при первом запуске.

### Требования

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) для Windows или установленный Docker Engine для Linux.
    
- [Git](https://git-scm.com/downloads) для клонирования репозитория.
    
- Подключение к интернету для загрузки базовой модели.
    
- Свободное место на диске для Docker-образа и файлов модели
  
### 1. Клонирование репозитория

Откройте терминал и выполните:Qwen2.5-0.5b-Jailbreaking-Lab.git

```
git clone https://github.com/tagoki/Qwen2.5-0.5b-Jailbreaking-Lab.git
cd Qwen2.5-0.5b-Jailbreaking-Lab.git
```

Либо скачайте репозиторий в формате ZIP и распакуйте его.

### 2. Сборка Docker-образа

Находясь в корневой директории репозитория, выполните:

```
docker build -t qwen-lab .
```

Docker соберёт образ на основе `ollama/ollama` и добавит в него конфигурацию лаборатории.

Проверить наличие образа можно командой:

```
docker images
```

## Запуск лаборатории

### 1. Создание контейнера

```
docker run -d \
  --name qwen-lab \
  -p 11434:11434 \
  -v ollama_data:/root/.ollama \
  qwen-lab
```

Для **Windows PowerShell** используйте команду в одну строку:

```
docker run -d --name qwen-lab -p 11434:11434 -v ollama_data:/root/.ollama qwen-lab
```

Параметры запуска:

|Параметр|Назначение|
|---|---|
|`-d`|Запуск контейнера в фоновом режиме|
|`--name qwen-lab`|Имя контейнера|
|`-p 11434:11434`|Доступ к API Ollama через локальный порт|
|`-v ollama_data:/root/.ollama`|Сохранение моделей в Docker volume|
|`qwen-lab`|Имя собранного образа|

### 2. Загрузка базовой модели

Выполните:

```
docker exec qwen-lab ollama pull qwen2.5:0.5b
```

Дождитесь завершения загрузки.

### 3. Создание модели лаборатории

Примените конфигурацию из `Modelfile`:

```
docker exec qwen-lab ollama create my-qwen -f /app/Modelfile
```

После завершения команда создаст модель `my-qwen` с заданными параметрами.

## Работа с моделью

### Интерактивный режим

Запустите диалог с моделью:

```
docker exec -it qwen-lab ollama run my-qwen
```

Теперь можно отправлять сообщения и проводить эксперименты с системными инструкциями.

Для выхода из диалога используйте:

```
/bye
```

### Проверка через API

Ollama предоставляет локальный HTTP API на порту `11434`.

Пример запроса в PowerShell:

```
$body = @{
    model = "my-qwen"
    prompt = "Привет! Представься."
    stream = $false
} | ConvertTo-Json

Invoke-RestMethod `
    -Uri "http://localhost:11434/api/generate" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body
```

В ответе будет JSON с результатом генерации.

## Управление контейнером

**Посмотреть запущенные контейнеры:**

```
docker ps
```

**Посмотреть логи:**

```
docker logs qwen-lab
```

**Остановить лабораторию:**

```
docker stop qwen-lab
```

**Повторно запустить остановленный контейнер:**

```
docker start qwen-lab
```

**Удалить контейнер:**

```
docker rm -f qwen-lab
```

Удаление контейнера не удаляет Docker volume `ollama_data`. Загруженные модели сохранятся и будут доступны после создания нового контейнера с тем же томом.

## Обновление конфигурации

Если вы изменили `Modelfile`, пересоздавать Docker-образ необязательно: файл можно скопировать в работающий контейнер и пересоздать модель.

```
docker cp Modelfile qwen-lab:/app/Modelfile
docker exec qwen-lab ollama create my-qwen -f /app/Modelfile
```

Если вы изменили `Dockerfile` или другие файлы, которые копируются при сборке, пересоберите образ:

```
docker build --no-cache -t qwen-lab .
```

Чтобы применить новый образ, удалите старый контейнер и создайте новый, сохранив прежний volume `ollama_data`.

> [!NOTE]  
> После изменения базовой модели в `Modelfile` необходимо предварительно загрузить новую модель командой `ollama pull`. Изменения конфигурации не удаляют сохранённые модели автоматически.
